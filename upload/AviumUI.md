# What's AviumUI (CN)

> ✨ **AviumUI 是一个由国内发起、基于 LineageOS 的定制项目**

我们专注于用户所需、美观界面、原汁原味、强化功能等理念的发展。\
我们不断吸取来自各种 ROM 的优秀功能，同时创造独一无二的新奇体验。\
每一项功能的增加都经过深思熟虑，在开发难度与体验之间寻找最佳平衡。\
我们的目标是：\
**提供真正需要、无缝融入日常使用习惯的系统体验。** 😉

# 🎃 Feature

------------------------------------------------------------------------

## 🪙 NFC

-   新增 **无感支付**\
    （通过识别 NFC 标签快速跳转到目标应用，目前已支持 **支付宝、银联**）

------------------------------------------------------------------------

## 🌙 Moon Suggestion（使用场景上下文建议）

-   在屏幕半暗时点击屏幕 → 建议 **屏幕常亮**\
-   开启手电筒时 → 建议 **快速关闭**\
-   连接到耳机时 → 推荐打开常用音乐 App\
-   复制 App 链接时 → 推荐快速打开 App\
-   复制快递单号 → 推荐快速查询\
-   基于上下文使用浮动图标提供快捷操作

------------------------------------------------------------------------

## 🪄 Avium 绝招

### 状态栏歌词

### 音乐锁屏

-   播放音乐时显示 **黑胶唱片效果**，增强沉浸感

### UI 深度扩展

-   禁用锁屏压暗\
-   启用桌面 **全层级模糊效果**\
-   应用开闭时模糊底部图层\
-   启动对应应用时允许 **暂时禁用所有传感器 6 秒**\
-   长按屏幕导航条 → 启用 **屏幕 OCR**\
-   允许用户遍历当前视图树以提取资源文件\
-   **强制截图** 功能
