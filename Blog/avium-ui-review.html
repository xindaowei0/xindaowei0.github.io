什么是 AviumUI？ ​

✨ AviumUI 是一个由国内发起、基于 LineageOS 的定制系统项目

我们专注于用户所需、美观界面、原汁原味、强化功能等理念的发展。不断吸取来自各种 ROM 的优秀功能，同时创造独一无二的新奇体验。每一项功能的增加都经过深思熟虑，在开发难度与体验之间寻找最佳平衡。

我们的目标是：提供真正需要、无缝融入日常使用习惯的系统体验。 😉

👉 AviumUI 官方网站

🌟 核心功能特性 ​

🪙 NFC 无感支付 ​

通过识别 NFC 标签快速跳转到目标应用，目前已支持 支付宝、银联，让支付更加便捷高效。

🌙 Moon Suggestion 上下文建议 ​

智能识别使用场景，提供贴心建议：

  • 在屏幕半暗时点击屏幕 → 建议 屏幕常亮
  • 开启手电筒时 → 建议 快速关闭
  • 连接到耳机时 → 推荐打开常用音乐 App
  • 复制 App 链接时 → 推荐快速打开 App
  • 复制快递单号 → 推荐快速查询
  • 基于上下文使用浮动图标提供快捷操作

🪄 Avium 绝招功能 ​

状态栏歌词 ​

实时显示正在播放的音乐歌词，让你在使用手机时也能轻松查看歌词。

音乐锁屏 ​

播放音乐时显示 黑胶唱片效果，增强音乐沉浸感，让锁屏不再单调。

UI 深度扩展 ​

  • 禁用锁屏压暗功能
  • 启用桌面 全层级模糊效果
  • 应用开闭时模糊底部图层
  • 启动应用时允许 暂时禁用所有传感器 6 秒
  • 长按屏幕导航条 → 启用 屏幕 OCR 功能
  • 允许用户遍历当前视图树以提取资源文件
  • 强制截图 功能，突破应用限制

🕒 万象时钟（全新锁屏系统） ​

  • 引入全新的锁屏框架
  • 新增 16 种全新锁屏样式
  • 支持 高阶材质效果（Material You / Blur / 动态）
  • 个性化定制程度高，满足不同用户需求

🖼 景深壁纸 ​

  • 带来更加沉浸的壁纸体验
  • 景深随视图变化产生动态效果
  • 让你的桌面更具层次感和立体感

📡 设备互传 - CatShare ​

  • 引入全新的文件选择界面
  • 深度融合系统，操作流畅
  • 与兼容「互传联盟」的设备直接共享文件
  • 高速传输，无需网络

🧩 多任务协同 ​

气泡小窗（增强版） ​

在原有气泡通知基础上支持直接启动应用，提升多任务处理效率。

轻量小窗 ​

  • 通过手势快速唤醒
  • 即用即走，轻量便捷
  • 不占用过多系统资源

手势唤醒 ​

从屏幕底部两侧向中心滑动即可唤醒菜单，操作更加快捷。

⚡ 闪光速记 ​

  • 快速记录复制内容并可立即编辑
  • 让灵感不丢失、效率更顺手
  • 支持多种格式的内容记录

🧭 系统 UI / UX 优化 ​

轻盈图标 ​

更加清新、现代的图标设计，提升整体视觉体验。

📱 支持机型 ​

AviumUI 支持多种机型，包括红米、小米等系列设备。具体支持机型可前往 官方网站 查看。

📥 下载与安装 ​

  1. 前往 AviumUI 官方网站 下载对应机型的固件包
  2. 确保设备已解锁 Bootloader
  3. 使用 Recovery 刷入固件包
  4. 首次启动可能需要较长时间，请耐心等待

💬 社区与支持 ​

  • 官方网站：https://aviumui.org
  • 官方论坛：https://forum.aviumui.org
  • Telegram 群组：https://t.me/aviumui

📝 总结 ​

AviumUI 是一款非常出色的类原生定制系统，它在保持原生系统流畅度的同时，加入了许多实用的功能和精美的设计。无论是 NFC 无感支付、上下文建议，还是状态栏歌词、音乐锁屏，都能让用户的日常使用更加便捷和愉悦。

如果你厌倦了原厂系统的臃肿，又想要一个功能丰富、流畅稳定的系统，那么 AviumUI 绝对值得一试！
